# Retail Growth Opportunity & Profitability Analytics

## Project Snapshot

180,519 Transactions
65,752 Orders
20,652 Customers
50 Product Categories

## Key Findings

• Top 40% customers generated 79.2% sales and 78.0% profit
• 8 Core Product categories generated ~85% sales and profit
• 54.8% order completion rate
• >50% delivery delay rate
• Shop By Sport identified as the strongest growth opportunity

- Order Fulfillment
